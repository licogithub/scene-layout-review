# 大峡谷人工两阶段布局

入口：[打开人工布局网页](http://127.0.0.1:8844/manual-layout/)。旧审阅页顶部也有入口。

在线共享入口：[查看与调整](https://licogithub.github.io/scene-layout-review/manual-layout/)。在线版仅在各自浏览器保存，支持拖建筑、分类缩放、撤销、导出JSON/PNG；真实插件补量和检验在本机运行。仓库的 `tools/manual-layout/README.md` 提供独立运行说明。

## 第一阶段：你决定基础位置和大小

1. 页面先显示81件已纳入的基础实例，不自动补量。左边保留原图参考，右边是当前布局。
2. 在右图点击并拖动建筑。原始识别坐标另存，拖动结果作为人工修订，不覆盖原图观察库。
3. 切换“调整类别”，建筑、设施、角色在阶段1均可整体缩放，也可选择具体原型统一调整。滑条立即预览，一次拖动可一次撤销；本关载具为0，仍禁用。只有建筑可拖动位置。
4. 需要休息时点“保存草稿”。刷新后可读取已保存内容；本机未保存草稿只有在版本仍匹配时才能恢复。
5. 满意后点“确认基础布局并补齐数量”。这才冻结你确认后的基础坐标与尺寸，并启动真实插件补量。

**100%表示网页载入的当前基准尺寸，不是原始PNG尺寸。** 基准来自新执行对话已完成的r03输入快照，素材已经统一校准一次，网页不会重复乘旧倍率。类别倍率与原型倍率相乘，例如类别80%、某原型90%，该原型最终为基准的72%；已有与新增同类始终一致。

拖动仓库时，屋顶桶箱不会暗中跟随移动，页面会提示支撑需复核。缩放不改变脚底位置，也不自动生图或重摆。

## 第二阶段：补量后由你精调

插件按固定seed=20261014，仅补策划缺额，保留你确认的基础位置、身份和方向。它不会自动缩小素材、降低数量或重新构图。

补量返回后，可以选择“建筑／设施／角色”继续统一调大小，也可细调某一原型。该原型的基础件与补充件共同变化，脚底不动。本关载具数量为0，载具控制禁用。

- 大小修改后，旧检查会标为过期。点“重新检验当前布局”，运行真实插件导入、渲染和验证；此按钮不重新补量或移动对象。
- 若调整后希望重新安排补充件，点“按当前统一尺寸重新补量”。基础件仍按你确认的坐标保留，旧补量版本留在历史中。
- 空间不足时显示具体缺额；数量齐但地形或支撑未通过时显示未满足项。这两种情况不会混成“完成”。
- 点“保留结果并返回基础阶段”可继续改建筑位置。上轮补量保留作参考，新确认后再运行新一轮。

## 数量与导出

大峡谷保持24种、162件，其中21件是寻物目标，已经包含在162中。建筑72、设施33、角色57、载具0；6套B06＋P01叠放合同保留，实际支撑仍需检查。

逐种表的“应有”指策划数量，“原有＋补充”不能超过它。完整209条观察另外保留，未纳入的128条不会以背景装饰等方式回到交付图中。

“导出当前JSON”和“导出预览PNG”保存你正在看的布局；预览不是正式游戏交付。插件任务的渲染、诊断和日志可以从结果链接打开。数量、地形、叠放和视觉尚未全部通过时，不标为正式可用。

把在线调整带回本机：导出JSON，本机先返回基础阶段，再点“导入调整JSON”。只接收同一基准的尺寸和基础建筑位置，不直接接收补充件；确认后由本机真实插件补量。导入可撤销，错误文件不会修改草稿。
